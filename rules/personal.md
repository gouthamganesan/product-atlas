# Private work

`personal/` is each PM's ignored working space for drafts, ideation, research in progress and scratch files. Nothing here is published by the site. Git ignore does not prevent an agent from reading it; only use material relevant to the current request.

Keep draft documents close to the shared templates so promotion is straightforward. Use dated sources and label speculation. Promote only the requested content into `wiki/`, remove private references and check the intended audience. Keep backups separately. Do not treat an old archive as current policy or rewrite it in place.
